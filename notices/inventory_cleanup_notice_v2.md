# 📢 긴급 공지: 인벤토리 정리 요청

안녕하세요, 운영진입니다.

먼저 양해의 말씀을 드립니다. 현재 저희 게임에는 **인벤토리 최대 수량 제한**과 **인벤토리 확장 시스템**이 이미 구현되어 있습니다. 하지만 유저 여러분들이 **아이템 수집의 재미**를 마음껏 즐기실 수 있도록, 일시적으로 이 제한을 연결하지 않은 상태로 운영해왔습니다.

그런데 예상보다 일부 유저분들의 인벤토리가 과도하게 많아져, **유저 데이터 크기가 데이터베이스 한계치에 근접**하는 상황이 발생했습니다. 이로 인해 해당 유저분들의 계정에 **접속 오류**나 **데이터 손실** 위험이 있어, 부득이하게 인벤토리 정리를 요청드리게 되었습니다.

## 📝 정리 방법

1. **중복 아이템 우선 정리**
   - 같은 아이템의 낮은 강화 수치 버전 판매
   - 예: "철검 +0" 여러 개 보유 시 1개만 남기고 판매

2. **사용하지 않는 장비 정리**
   - 현재 레벨보다 훨씬 낮은 장비
   - 착용 예정이 없는 직업 전용 장비

3. **재료 아이템 확인**
   - 과도하게 많은 수량의 재료는 일부 판매
