## 🎯 클래스별 상세 평가

### 1. 전사 (⚔️ Warrior)
**현재 상태**: 균형잡힘
- **장점**:
  - 불굴의 의지(10% 확률 40% 피해 감소)가 생존력 제공
  - 체력 30% 이하 광전사 모드(20% 공격력 증가)
  - 방어 관통(체력의 8%)으로 탱커 상대 유리
- **단점**:
  - 너프 후에도 여전히 안정적인 성능
  - 특별히 압도적이지는 않음
- **평가**: 너프가 적절히 적용되어 균형잡힌 상태

### 2. 법사 (🔮 Mage)
**현재 상태**: 약간 강함
- **장점**:
  - 최고 평균 전투력 (108.7%)
  - 원소 데미지(지능의 25%)로 추가 피해
  - 20% 확률 연쇄 번개(60% 추가 피해)
- **단점**:
  - 생존 기술 부재
  - 민첩/회피 기반 클래스에 취약
- **평가**: 5% 너프에도 여전히 강력. 추가 너프 고려 필요

### 3. 궁수 (🏹 Archer)
**현재 상태**: 균형잡힘
- **장점**:
  - 30% 2연타 + 15% 추가 크리티컬
  - 버프 후 적절한 딜링 능력
  - 민첩 기반 치명타 빌드 가능
- **단점**:
  - 여전히 평균 이하 전투력(97.6%)
  - 상위권 진입 어려움
- **평가**: 버프가 효과적이었으나 여전히 약간 부족

### 4. 도적 (🗡️ Thief)
**현재 상태**: 약함
- **장점**:
  - 회피 시 50% 반격으로 카운터 플레이
  - 그림자 공격으로 순간 폭딜
  - 민첩+행운 균형 시 15% 시너지 보너스
- **단점**:
  - 최저 평균 전투력(91.7%)
  - 버프에도 불구하고 여전히 약함
- **평가**: 추가 버프 필요

### 5. 수호자 (🛡️ Defender)
**현재 상태**: 데이터 부족
- **장점**:
  - 15% 보호막 + 8% 기본 방어
  - 20% 확률 방어 기반 반격
  - 뛰어난 생존력
- **단점**:
  - 낮은 딜링 능력
  - 장기전에서 라운드별 데미지 증폭에 불리
- **평가**: 현재 플레이어 없어 정확한 평가 어려움
