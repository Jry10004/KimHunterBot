# PVP 강화 시스템 완전 가이드 (신규 3스킬 시스템)

## 📋 시스템 개요

Discord 봇의 PVP 시스템이 기존 펜듈럼 스킬(상단/중단/하단)에서 전략적 3스킬 시스템(강공/균형/회피)으로 전면 개편되었습니다.

## 🎮 3스킬 시스템 상세

### 🗡️ 강공 (High Risk, High Reward)
- **기본 속성**
  - 데미지: 105% → 130% (레벨 100)
  - 명중률: 70% → 80% (레벨 100)
  - 성공 시: 다음 턴 공격력 +5~15%
  - 실패 시: 다음 턴 방어력 -5~15%

### ⚖️ 균형 (Stable Choice)
- **기본 속성**
  - 데미지: 85% → 95% (레벨 100)
  - 명중률: 100% (항상 적중)
  - 방어 무시: 5% → 20% (레벨 100)
  - 다음 턴 방어력: +5~15%

### 💨 회피 (Defensive Counter)
- **기본 속성**
  - 데미지: 30% → 50% (레벨 100)
  - 명중률: 100% (항상 적중)
  - 회피율: 15% → 40% (레벨 100)
  - 반격 배율: 1.3배 → 1.8배

## 💎 강화 시스템 (곡괭이 시스템과 동일한 설계)

### 강화 효과
각 스킬은 개별적으로 0~100레벨까지 강화 가능합니다.

#### 🗡️ 강공 강화
- 데미지: +0.4% per level (최대 +40%)
- 명중률: +0.2% per level (최대 +20%)

#### ⚖️ 균형 강화  
- 방어 무시: +0.5% per level (최대 +50%)
- 방어력 증가: +0.3% per level (최대 +30%)

#### 💨 회피 강화
- 회피율: +0.6% per level (최대 +60%)
- 반격 데미지: +0.4% per level (최대 +40%)

### 강화 비용
- 각 레벨당 5,000 골드
- 최대 강화 시 총 1,500,000 골드 필요 (150만)

## 🎯 전투 데미지 계산 과정

### 1단계: 기본 스킬 스탯 계산
```javascript
// 레벨 100 기준 예시
const skillStats = {
    'high': { 
        damage: 1.05 + (100 * 0.0025) = 1.30,
        accuracy: 0.70 + (100 * 0.001) = 0.80,
        successBuff: 0.05 + (100 * 0.001) = 0.15,
        failDebuff: 0.05 + (100 * 0.001) = 0.15
    }
};
```

### 2단계: 강화 효과 적용
```javascript
// 강공 100레벨 강화 시
damage: 1.30 + (100 * 0.004) = 1.70 (170%)
accuracy: 0.80 + (100 * 0.002) = 1.00 (100%)
```

### 3단계: 명중 판정
```javascript
if (Math.random() < skillBonus.accuracy) {
    // 공격 성공
} else {
    // 공격 실패 (강공의 경우 디버프 적용)
}
```

### 4단계: 데미지 계산
```javascript
// PVP 데미지 계산 (calculatePvPDamage 함수)
const baseDamage = calculateDamage(attacker, defender, {
    skillMultiplier: 1.2, // 강공 기본 배율
    damageType: 'physical',
    additionalCrit: 0.05  // 강공은 추가 크리티컬
});

// 강화로 인한 최종 배율 적용
const finalDamage = baseDamage * skillBonus.damage;
```

### 5단계: 특수 효과 적용
- **강공 성공**: 다음 턴 공격력 버프
- **균형**: 방어 무시 데미지 + 다음 턴 방어력 증가
- **회피**: 회피 성공 시 반격 데미지

## 📊 실전 예시

### 케이스 1: 강공(100강) vs 회피(0강)
```
플레이어 A (강공 100강):
- 데미지: 170%
- 명중률: 100% (최대치 도달)
- 공격 성공 시: 다음 턴 공격력 +15%

플레이어 B (회피 0강):
- 데미지: 30%
- 회피율: 15%
- 회피 성공 시: 1.3배 반격

결과:
- 100% 확률로 A의 강공 적중 → 170% 데미지
- 회피 불가능 (A의 명중률이 100%)
```

### 케이스 2: 균형(50강) vs 회피(50강)
```
플레이어 A (균형 50강):
- 데미지: 90%
- 방어 무시: 30% (5% + 50*0.5%)
- 다음 턴 방어력: +20%

플레이어 B (회피 50강):
- 데미지: 40%
- 회피율: 45% (15% + 50*0.6%)
- 반격 배율: 1.5배 (1.3 + 50*0.004)

결과:
- 55% 확률로 A의 균형 적중 → 90% 데미지 (30% 방어 무시)
- 45% 확률로 B의 회피 성공 → A가 60% 반격 받음
```

## 🎮 사용 방법

1. **PVP 메뉴 진입**: `!pvp` 또는 PVP 버튼 클릭
2. **공격 강화 선택**: 💎 공격 강화 버튼 클릭
3. **스킬 선택 강화**: 원하는 스킬 강화 버튼 클릭
4. **대전 시작**: ⚔️ 대전방 만들기
5. **스킬 선택**: 각 라운드마다 3개 스킬 중 선택

## 📈 전략 가이드

### 강공 위주 빌드
- 장점: 높은 데미지, 버프 누적 가능
- 단점: 낮은 명중률, 실패 시 페널티
- 추천: 공격적인 플레이 스타일

### 균형 위주 빌드
- 장점: 안정적인 데미지, 방어 무시
- 단점: 낮은 최대 데미지
- 추천: 안정적인 플레이 스타일

### 회피 위주 빌드
- 장점: 높은 회피율, 강력한 반격
- 단점: 낮은 기본 데미지
- 추천: 수비적 카운터 플레이

## 🔧 기술 구현 상세

### 파일 위치
- `/systems/pvpSystem.js`: 메인 PVP 로직
- `/handlers/pvp/pvpMenu.js`: UI 및 강화 메뉴
- `/handlers/common/damageCalculator.js`: 데미지 계산

### 주요 함수
- `getSkillStats()`: 레벨 기반 스킬 스탯 계산
- `processPVPEnhance()`: 강화 처리
- `calculatePvPDamage()`: PVP 데미지 계산
- `resolveRound()`: 라운드 결과 처리

## 🎯 밸런스 설계 철학

1. **가위바위보 관계 제거**: 모든 스킬이 상황에 따라 유용
2. **리스크와 보상**: 높은 위험에는 높은 보상
3. **전략적 선택**: 상대 패턴 읽기가 중요
4. **강화 가치**: 투자한 만큼의 명확한 이득
5. **다양한 플레이스타일**: 각 스킬이 독특한 전략 제공
